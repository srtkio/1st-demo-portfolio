Product Thinking Framework How Sarthak approaches problems: from user friction to measurable software solutions
01

Spotting everyday friction, manual inefficiencies, or broken workflows.

02

Understanding stakeholder constraints, field conditions, and true pain points.

03

Define Core Problem

Distilling complexity into a clear, single, testable problem statement.

04

Explore Solutions

Brainstorming low-friction interventions and technical trade-offs.

05

Prototype

Crafting interactive flows, mockups, or lightweight code proofs of concept.

Testing with real peers or users, measuring clarity vs confusion.

Writing clean, auditable code with standard frameworks and solid documentation.

08

Learn from Feedback

Analyzing usage data, edge cases, and feeding insights into next iteration.
